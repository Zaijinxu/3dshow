# 《蛤蟆的心灵归途》作品交互展示网站

基于 Blender 的三渲二动画短片《蛤蟆的心灵归途》(The Soul Journey of the Toad) 的交互式作品展示页。

## 如何打开

**方式一（最简单）**：双击 `index.html` 即可在浏览器中查看。
视频、图片全部为本地相对路径引用，离线可用（仅在线字体需要联网，无网络时自动回退系统字体）。

**方式二（推荐，体验更佳）**：在本地起一个静态服务器：

```bash
# 任选其一
python -m http.server 8000        # 有 Python 时
npx serve .                       # 有 Node.js 时
```

然后访问 http://localhost:8000

## 页面板块

| 板块 | 内容 | 交互 |
|---|---|---|
| 首屏 Hero | 作品标题、简介、蛤蟆立绘 | 鼠标视差、浮动动画 |
| 影片放映 | 正片 4'10" 全高清播放 | 点击播放 |
| 故事四幕 | 四幕剧情 + 对应色调 | 自动轮播 / 手动切换 |
| 角色图鉴 | 蛤蟆/苍鹭/獾/鼹鼠 人设卡 | 角色切换、贴纸切换 |
| 场景画廊 | 四大场景渲染图 | 点击灯箱放大 |
| 分镜手稿 | 四张分镜草图 | 横向拖拽/滚轮、灯箱 |
| 制作历程 | 九步制作流程时间线 | 滚动点亮、图片放大 |
| 技术特色 | 三渲二/蜡笔/色彩心理学 | — |
| 关于作品 | 创作初衷与作品数据 | — |

全局交互：导航滚动高亮、平滑滚动、图片灯箱（键盘 ← → Esc）、返回顶部、移动端自适应。

## 目录结构

```
作品展示网站/
├── index.html            # 单文件页面（含全部样式与脚本）
├── README.md
└── assets/
    （在线版：正片通过B站嵌入播放，BV1WKNd65EnD，不在本地存放视频文件）
    ├── poster/           # 视频封面帧
    ├── characters/       # 角色贴纸（透明底 webp）+ 设定总览图
    ├── scenes/           # 四大场景渲染图
    ├── storyboard/       # 分镜手稿（原素材即为小图，已按原尺寸展示）
    └── process/          # 制作过程截图（场景三视图、建模、绑定、渲染节点、机位、蜡笔、后期）
```

## 素材说明

- 所有图片已由 PNG 压缩为 WebP（透明贴纸保留 Alpha 通道），体积约为原来的 1/5。
- 分镜手稿原始素材分辨率较低（260–390px），页面按原尺寸展示以保证清晰；如需放大查看请提供高清原图替换 `assets/storyboard/` 下同名文件。
- 正片使用B站嵌入播放器（index.html 中搜索 BV1WKNd65EnD 可更换视频）。

## 后期修改指引

- 文案集中在 `index.html` 的 `ACTS`（故事四幕）与 `CHARACTERS`（角色数据）两个 JS 数组，改文字无需动布局。
- 主色调在 `:root` CSS 变量中统一调整（绿色系 `--green-*`、强调黄 `--yellow-*`）。
